How publishing works. This page runs only in your browser — it can't change the live site by itself.
  1. Edit below and press Preview to see the site with your changes (only you see this).
  2. Press Export data.js to download the updated content file.
  3. On GitHub, open assets/ in the portfolio repo, choose Add file → Upload files, upload data.js and commit. The live site updates in a minute or two.
To add a CV, upload the PDF to assets/ first (for example assets/resume.pdf) and put that path in the Resume field.
