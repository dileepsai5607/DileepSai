## Built with

- Plain HTML, CSS and JavaScript in a single `index.html`, with no build step or framework
- Canvas animations for the particle field and the philosophy panel
- Variable fonts from Google Fonts (Roboto Flex, Josefin Sans, Poppins, Inter, JetBrains Mono)
- Hosted free on GitHub Pages

Animations are turned off for visitors who have reduced motion enabled, and the custom cursor appears only on devices with a mouse.

## Run locally

No installation needed. Clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/dileepsai5607/portfolio.git
cd portfolio
```

To serve it the same way GitHub Pages does:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
